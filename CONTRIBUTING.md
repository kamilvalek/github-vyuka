# Jak přispívat

Tento repozitář slouží k výuce GitHubu.

## Před zahájením práce

- Přečtěte README.
- Ověřte, zda podobné issue nebo PR již neexistuje.
- Větší změnu nejprve popište v issue.

## Příprava změny

1. Vytvořte větev z aktuální hlavní větve.
2. Připravte jednu srozumitelnou změnu.
3. Použijte výstižné zprávy commitů.
4. Otevřete PR a vysvětlete co a proč měníte.
5. Zkontrolujte Files changed a zapracujte připomínky.

## Kontrola

- Markdown musí být čitelný v náhledu.
- Odkazy musí vést na správné místo.
- Při změně HTML vyzkoušejte stránku v prohlížeči.
- Používejte pouze cvičné údaje.

O přijetí návrhu rozhoduje správce projektu.
