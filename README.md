# GitHub — můj cvičný projekt

Tento repozitář používám k procvičování práce s GitHubem.

## Cíl projektu

Vytvořit jednoduchý HTML web a naučit se spravovat jeho změny.

## Co si vyzkouším

- práci se soubory a dokumentací,
- historii změn,
- větve a kontrolu navržených úprav,
- publikování jednoduchého webu.

## Pravidla

Používám pouze cvičné údaje.
Nevkládám hesla, přístupové klíče ani skutečné osobní údaje.

## Jak s projektem pracovat

Projekt je zatím ve fázi přípravy.
HTML stránka bude přidána v další lekci.

1. Otevřete tento repozitář.
2. Přečtěte si soubor `README.md`.
3. Prohlédněte si dostupné soubory na záložce Code.

## Plán práce

- [x] Připravit úvodní dokumentaci.
- [x] Vytvořit soubor index.html.
- [ ] Procvičit větve a kontrolu změn.
- [ ] Publikovat cvičný web.

## Ukázka budoucí stránky

Následující kód je pouze ukázka v dokumentaci:

```html

```

Každou dokončenou úpravu ukládám jako commit.
Zpráva commitu stručně vysvětluje, co jsem změnil.
Díky historii mohu dohledat starší podobu dokumentace.
