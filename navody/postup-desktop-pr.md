# Jak navrhnout změnu z GitHub Desktop

Ukázka pro fiktivní projekt obce Ukázkov.

1. Aktualizovat místní větev main.
2. Vytvořit novou pracovní větev.
3. Upravit soubor a uložit jej.
4. Zkontrolovat změny a vytvořit commit.
5. Publikovat větev na GitHub.
6. Otevřít pull request do main.
7. Po kontrole změnu sloučit.
